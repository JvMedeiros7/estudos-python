# 🐍 Estudos de Python

Meu repositório de estudos de **Python** — do básico à orientação a objetos.
Reúne exercícios, desafios e miniprogramas, boa parte acompanhando o curso
**Python 3 (Curso em Vídeo / Gustavo Guanabara)**.

## 📂 Organização por tema

| Pasta | Conteúdo |
|---|---|
| `01-fundamentos/` | Aulas iniciais, operadores, condicionais e laços de repetição |
| `02-estruturas-dados/` | Listas, tuplas, dicionários, conjuntos e strings |
| `03-funcoes-modulos/` | Funções, módulos e pacotes |
| `04-poo/` | Programação Orientada a Objetos |
| `05-desafios/` | Exercícios numerados do curso (exe090+) e desafios resolvidos |
| `06-mini-programas/` | Projetinhos completos: caixa eletrônico, jogos, calculadoras... |

## 🚀 Como executar

```bash
python caminho/do/arquivo.py
```

> Requer [Python 3](https://www.python.org/downloads/) instalado.

## 🎯 Objetivo

Praticar programação na base do "aprender fazendo" — cada arquivo é um conceito
exercitado. O repositório cresce conforme avanço nos estudos.
